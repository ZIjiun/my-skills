# 更新紀錄

## 2026-11-16（第二次）

- 三問改成一組：她需要嗎、她好接嗎、他想達到什麼。原本的「現在合適嗎」併進「她好接嗎」。
- 判斷表加狀況 7：使用者想主動告訴她一件她沒問的事。預設直說（事實 → 影響或目的 → 請求），講一次就停；真的有問題要問才用問句。
- 使用者堅持要講沒過三問的事時，問一次他的目的，再找做法，不重複叫他先不要講。
- 事後檢討的結尾固定列出下一步。
- 為什麼改：實際遇到。同一天檢討時，使用者反覆說想讓她知道她也有同樣的寫法，skill 連續幾輪只回「晚點再講」，直到問出目的才找到做法；分析太多，使用者得自己問「所以要怎麼回」。同時三問出現兩組說法，統一成一組。
- 對照過兩個參考來源的原文，沒有衝突；「預設直說」是依非暴力溝通的請求原則調整的。

## 2026-11-16

- 新增「傳之前三問」（她需要嗎、她好接嗎、現在合適嗎），核心是讓她好接。草稿不管是使用者貼的還是 skill 寫的，都先過三問再修文字。
- 新增原則：先謝再認；想提醒她那邊的問題要換時間、換方式（真的需要答案才用請教的）；沒查證的判斷要標出來。
- 「先接、再補、後說明」補一句：原因她已經知道時，後說明可以省略。
- 使用者貼草稿時，改成先用三問決定留哪些，留下的部分才保留原本用字。
- 背景加一種走偏方式；加一個三問的範例。
- 為什麼改：實際遇到。她指出一個問題並附了原因和修法，使用者道歉後貼了一段長的技術說明草稿來問，skill 只幫忙修順、建議拆成兩則並附圖，沒有先判斷這些她需不需要。傳出去後她沒有回。
